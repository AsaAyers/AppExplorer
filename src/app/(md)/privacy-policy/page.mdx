# Privacy Policy — AppExplorer

**Last updated:** 2026-02-08

AppExplorer (“the App”) is a Miro application available at https://appexplorer.dev.
We are committed to collecting and storing only the minimum data required to operate the App and manage subscriptions.

## 1. Information We Collect

### Miro User Information

When you use AppExplorer, the Miro SDK provides user data.  
We only store:

- **Miro User ID**

This is used solely to:

- Identify users within the App
- Associate users with subscription status

We do **not** store:

- Names
- Email addresses
- Profile images
- Board content
- Any additional Miro profile data

---

### Subscription & Billing Data

AppExplorer uses Stripe to manage subscriptions and payments.

We store only the minimum billing data required to manage access, such as:

- Stripe Customer ID
- Subscription ID
- Plan or pricing tier
- Subscription status

We do **not** store:

- Credit card numbers
- Bank details
- Billing addresses

All payment information is processed and stored by Stripe.

---

### Authentication Cookies

AppExplorer uses a session cookie to maintain authentication.

This cookie is:

- Required for login/session functionality
- Not used for tracking or advertising
- Not shared with third parties

Disabling cookies may prevent the App from functioning.

---

## 2. How We Use Data

We use collected data only to:

- Authenticate users
- Manage subscriptions
- Control feature access
- Maintain secure sessions

We do **not** use data for:

- Advertising
- Marketing analytics
- Behavioral tracking
- Sale to third parties

---

## 3. Data Sharing

We share data only with service providers necessary to operate the App:

- Stripe (payment processing)

We do not share data with advertisers or data brokers.

---

## 4. Data Retention

We retain data only as long as necessary to operate the service:

- Active accounts: retained for functionality
- Canceled subscriptions: retained for billing records
- Uninstalled users: data may be deleted or anonymized within a reasonable timeframe

---

## 5. Security

We use industry-standard safeguards, including:

- HTTPS encryption
- Secure authentication
- Restricted system access

---

Because we store minimal data, exports are limited to identifiers and subscription records.
